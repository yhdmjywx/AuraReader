# AuraReader 字体设置实现说明

字体功能复用视觉偏好面板原来的字体行。下拉按钮宽 180px，菜单按基础、中文、英文分组，选中后立即更新正文并关闭字体菜单。主面板仍为六行，不设置独立预览区域。

## 本轮完成范围

完成自动选择、两款离线精选字体（更纱黑体和 Literata）、本机字体搜索、TTF／OTF／WOFF2 导入、已导入字体复用、全局选择与搜索词持久化，以及字体加载失败时的系统回退。

按用户本轮调整，原书字体恢复暂缓；菜单保留“原书字体”项并标记“暂未启用”。未知语言暂使用系统字体回退。没有修改 EPUB 的出版方样式清理和内嵌字体解析行为。

## 自动选择与正文应用

`domain/fontCatalog.js` 维护两款精选字体及回退规则。EPUB 元数据语言优先，其次采用正文 `lang`／`xml:lang` 标记。简体中文使用 Sarasa Gothic SC，英文使用 Literata，其他或未知语言使用系统字体。语言字段随解析后的书籍保存；已导入且没有语言字段的旧书，选择自动时使用系统回退，可重新导入补齐语言元数据。之前选择了已移除内置字体的偏好会迁移为“自动选择”并保存。

`features/reader/fontController.js` 负责菜单、偏好和字体加载。字号、行高、段落间距等继续由现有阅读逻辑控制。字体切换前记录当前句子，切换及字体加载完成后经现有重排流程恢复阅读位置；字体覆盖仅作用于正文的 `font-family`，保留粗体、斜体及其他文字语义。

Literata 在缺少中文字形时回退到本地 Sarasa Gothic SC，浏览器按缺失字形处理，不逐字修改 DOM 或切换字体设置。本机及用户导入字体同样使用更纱黑体与系统字体回退，不再打包额外的中文回退字库。

## 本机字体与导入资源

“更多字体”在同一个菜单内显示返回、搜索、读取本机字体、导入和字体列表。本地 Windows 服务通过系统字体集合读取安装的家族名称，不复制系统字体文件。该读取接口仅向本机请求开放；其他部署环境可在浏览器支持时使用 Local Font Access API，无法读取时仍可导入字体文件。

本机字体通过独立别名优先加载 `local()` 字体，避免名称相同的内置网页字体覆盖用户的本机选择；本机字体名称解析失败时仍保留原生家族及系统回退。已有界面用的 Inter 和 Fira Code 字体引用保留，正文精选字库与这些界面字体独立。

`server/fontStore.js` 检查扩展名、文件签名和字体解析结果，拒绝空文件、损坏文件、伪装格式及超过 64MB 的文件。资源保存于项目的 `data/fonts/`，以内容 SHA-256 命名；同一文件再次导入不产生重复条目。文件与元数据在服务重启后继续存在，缺失或损坏时正文正常回退。

选择、搜索词和近期选择的系统家族分别保存在当前浏览器的 `aura_font_preference`、`aura_font_search`、`aura_font_recent_system` 中。该偏好对所有书籍生效，不写入单书备份。用户字体目录是应用资源，应在迁移应用目录时一并保留。

## 字库与验证

字库、许可证和来源说明放在 `src/client/assets/fonts/`。`tests/unit/test_fonts.js` 验证语言优先级、回退、导入格式校验、重复导入、资源缺失、重启持久化、六行界面结构及菜单交互；现有分页和标注回归继续执行。

内置资源仅保留更纱黑体四种字形和 Literata 的常规／斜体可变字重，共六个 WOFF2 文件及两份许可证。字体测试覆盖资源完整性、中文字形回退、已移除字体偏好的迁移和菜单选中状态；导入资源的格式校验、去重与持久化检查继续保留。
