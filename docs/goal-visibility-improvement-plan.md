# Goal 可视性与操作可辨识改进方案

2026-10-26。依据 GoalUI、styles.css 和第 1 轮真实桌面截图制定，现已实施并完成验收。下文保留方案，文末记录实际结果。

## 问题与取舍

上一轮完成了阅读表面的圆角、留白和阴影，Goal 内部仍沿用小字号、弱控件和悬停显示的旧样式。本轮优先解决看清信息、找到操作、准确点击，再继续侧栏与页面动画。

| 当前实现 | 具体问题 | 改进方向 |
| --- | --- | --- |
| 来源书名 11px，浅色 `#86909c`，暗色 `#64748b` | 浅色侧栏约 3.02:1，浅色主区约 3.24:1，暗色主区约 3.07:1，作为小字号信息不够清楚 | 来源升至 13px，使用满足文字对比度的次要文字色 |
| 材料摘要 13px，侧栏对比度约 6.62:1 | 对比度已经足够，仍因字号、两行截断和与其他元素样式接近而难扫读 | 摘要升至 15px，保持合理行距；侧栏最多 3 行，主区保留全文 |
| 普通 Goal 图标按钮 28px，材料解除关联 24px | 视觉图标偏小、点击余量有限 | 图标 18–20px，操作热区至少 32×32px，主要新建和页面导航高 36px |
| 子 Goal 新建与解除关联默认 opacity:0 | 没有悬停时看不出能做什么 | 核心操作常驻；解除关联保留低强调，但保持可见 |
| All goals、父级返回、材料折叠仅 12px，选中树节点只变蓝 | 导航难辨认，当前节点与普通行区分弱 | 导航 14px，选中行使用底色、字重及文字色共同表达 |
| 材料入口为回形针＋数字 | 收起后不能迅速判断它控制什么 | 替换为 `2 items`＋展开箭头，同一个按钮、同一种折叠逻辑 |
| `#3b82f6` 用于白底上的小字号交互文字 | 约 3.68:1，不足普通小字 4.5:1 目标 | Goal 独立动作色改深；不全局替换品牌色 |

上述对比度按当前 CSS 的不透明前景／背景色和 WCAG 相对亮度公式计算，保留两位小数仅供展示；并非对整个产品的无障碍合规认证，也未把截图抗锯齿像素当作设计色。

## 统一规格

### 文字与颜色

| 内容 | 侧栏 | Goal 主区 |
| --- | --- | --- |
| 当前 Goal | 18px / 600，行高 1.6 | 26px / 600，行高 1.5 |
| 子 Goal、树节点、材料摘要 | 15px，行高 1.6–1.7 | 16px，行高 1.6–1.7 |
| 导航、操作文案、材料数量 | 14px / 500 | 14px / 500 |
| 来源书名 | 13px，清楚可读的次要色 | 13px，清楚可读的次要色 |

主信息使用当前高对比正文色；次要文字通过字号与位置降低强调，不继续依赖低对比浅灰。建议浅色次要色从 `#475569` 起试，白底约 7.58:1；浅色动作色从 `#1d4ed8` 起试，侧栏底约 6.24:1。暗色次要色从 `#a8b4c7` 起试，主区底约 6.98:1。最终以真实 default、hover、selected、focus 背景逐一核验。

仅在 Goal 范围定义语义变量，例如 `--goal-text`、`--goal-secondary`、`--goal-action`、`--goal-selected-bg` 和 `--goal-focus`。阅读正文、纸张主题与其他模块的颜色不整体替换。

### 控件与层次

- `New goal` 使用加号与短文字，常驻，按钮高 36px；`All goals` 保持导航含义，不和新建做成同一种强强调按钮。
- `Subgoal` 在当前 Goal 附近常驻，复用原新建子 Goal 动作。与标题分开排布，给长标题保留宽度，不悬浮遮住标题。标题本身仍点击原位编辑，不增加编辑按钮。
- 展开／折叠树的箭头使用 32px 热区；节点文字区域使用自己的整行点击目标，单行至少高 36px。保持展开箭头与选择节点各自原来的行为。
- 父级返回、`All goals`、材料折叠至少高 32px；顶部 `Goals`、侧栏收放和 `Back to reading` 统一到至少 36px 高的目标。图标大小与热区分别定义。
- 解除关联 `×` 使用 32px 热区，默认可见，常态中性；hover／focus 才提高强调。与材料文字目标保留至少 8px 间隔，避免误点。材料摘要区域保持原文跳转，解除关联独立操作。
- 新建按钮提供稳定的浅底或细边界；普通导航和材料列表用清楚文字、留白与 hover／focus 背景表达可点性。不给每条材料增加卡片、阴影或装饰性分隔线。
- 当前树节点增加浅底和 600 字重，保留 `aria-current`；键盘焦点使用清楚的 2px 轮廓，保证不被圆角、滚动容器或相邻按钮裁掉。
- 归入按钮复用现有 linked 状态区分 `Goal` 与 `Linked`。已归入属于状态反馈，保留清楚的对勾和文字；禁用点击仍沿用原逻辑。仅调整 Goal 入口，不重做笔记操作区或高亮浮条。
- 220px 侧栏时允许工具行换行，必要时侧栏内边距降至 16px；不把文字或热区压回小尺寸。280px 默认侧栏和 640px 宽侧栏使用同一套规格。

## 四步实施

1. **先修颜色和文字。** 在 Goal 范围定义颜色与字号，调整标题、摘要、来源和导航；同步 textarea 字号／行高，避免进入编辑后文字变小、错位。保留已经完成的外层表面样式。
2. **再修可发现性和点击尺寸。** 放大控件热区与图标；核心操作常驻并增加必要的短英文标识。仅重排原按钮，复用现有事件，不增加菜单、弹层或操作步骤。
3. **统一状态和窄宽度表现。** 覆盖 hover、focus、selected、linked、disabled、空状态与长文字；同一套 GoalUI 在侧栏和主区都清楚。缺失来源不能只用浅灰表达，要保留现有明确状态文字。
4. **用实际尺寸验收。** 先做侧栏／主区的真实截图与操作复核，再运行针对性 DOM、键盘、编辑器和桌面回归。达标后继续原指导的动画阶段。

主要改动位置是 `styles.css` 与 `features/goals/goalUI.ts`。如需明确已有 linked 状态样式，限定在现有 Goal 按钮的状态呈现适配。Goal 存储、树结构、归入、解除关联、原文跳转与备份规则保持现有逻辑；不新增分类、状态、编辑面板或逐项卡片。

## 验收条件

- 普通有效文字对实际背景至少 4.5:1；当前 Goal 与材料摘要尽量达到 7:1。关键操作图标和识别状态所需的视觉线索至少 3:1。装饰阴影与轻边缘不统一加深，避免重新形成硬分界。
- 主要按钮高至少 36px；图标操作至少 32×32px，目标间距足够且互不重叠。此处是产品自己的桌面体验目标，高于 WCAG 24×24px 或间距例外的最低要求。
- 鼠标静止时能看见新建 Goal、子 Goal 操作和材料入口；Tab 能到达所有可操作目标，Enter／Space 沿用原行为，焦点完整可见。
- 在 220／280／640px 侧栏、独立 Goal 页面、亮／暗主题下检查；阅读纸张色不改变 Goal 文字对比度。检查中英混排、多行长标题、长书名和深层树。
- 在 100%、125%、150% 的窗口显示／浏览器缩放组合及 200% 文本放大场景复核：不截断操作、无目标重叠、不强行单行。只有需要保留两维结构的内容才允许例外，不以裁字维持固定行高。
- 新建、父子导航、归入即展开、点击材料定位、原位编辑／IME、焦点与光标、解除关联、跨书和返回阅读的既有回归继续通过。对比度核验使用实际计算颜色、背景与透明度合成，不只检查色板变量。

## 依据

- [W3C：文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)：普通文字 4.5:1，大字有相应例外。本方案对信息文字统一采用至少 4.5:1。
- [W3C：非文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)：识别有效控件与状态所必需的视觉信息至少 3:1；不是要求每条装饰边界达到这个值。
- [W3C：目标尺寸](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)：24×24 CSS px 或满足相应例外是最低要求；更大的目标仍有助于准确操作。

## 实施与验收结果

- Goal 侧栏标题 18px／600；主区标题 26px／600；材料与树节点侧栏 15px、主区 16px；来源 13px，导航 14px。编辑器与对应标题字号、字重和行高同步。
- 新建与子 Goal 采用常驻的加号＋短英文标签，按钮高至少 36px；解除关联与展开箭头使用 32px 图标热区。材料入口改为数量文字＋展开箭头，仍使用原折叠动作。
- 选中树行增加底色和字重；核心操作不再通过 opacity:0 隐藏。Goal 专用亮／暗主题颜色不改变全局品牌色或正文颜色。页边笔记中的 Goal 入口继承原纸张文字色，已归入保留清楚的 Linked 与对勾，仍按原逻辑禁用重复归入。
- 构建及严格类型检查通过；`npm test` 59 项通过，0 失败。真实 Electron 的阅读、笔记、Goal 与重启回归通过，原位编辑、光标、归入后展开、解除关联、跨书跳转和备份相关检查保留。
- 新增 `tests/desktop/goal-visibility.cjs` 在实际 Renderer 计算背景合成颜色、检查文字／图标对比度、热区尺寸和目标重叠。12 组场景通过：亮暗侧栏／主区、220px 侧栏与树、125%／150%／200% 页面缩放、长中英标题／书名／树节点、200% 单独文字放大。已测场景最低对比度为 5.65:1；不代表对产品其余区域的全面合规认证。
- 验证 Tab 焦点与 Enter 原生按钮激活；系统显示比例会将 CSS 声明的 2px 轮廓取整为设备像素，测试保留这一实际差异。
- 最终报告与截图：`.commandcode/desktop-tests/run-VhXmhH/`，其中 `goal-visibility-results.json` 保存各控件实测值，`goal-default.png`／`goal-compact.png` 为侧栏，`goal-page.png`／`goal-page-dark.png` 为主区。完整回归日志为 `.commandcode/goal-visibility-tests.log`。
- 本轮改动限定展示与已有 Goal 按钮的状态文案，未调整存储、树关系、归入或备份规则；后续仍可按原指导继续动效阶段。
