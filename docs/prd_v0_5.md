## 1. 目标用户是谁 (Target Users)

- **深度研读者与学者 / 知识工作者**：对 EPUB、PDF、TXT 电子书进行深度文本研读，需要单页 / 双页（Spread 对开）逼真实体书卷排版、NCX 132 条规范目录毫秒级锚点导航、书内超链接防丢失拦截以及免受外网中断影响的极致阅读体验。
- **卡片盒笔记重度用户 (Obsidian / Logseq / Notion 用户)**：注重高信噪比与知识沉淀，追求纯净行内 `==高亮==` 语法嵌入、段落下方绝无二次粘贴废话、分章节 Zip 打包结构化笔记，便于无缝导入个人知识库体系。
- **极致隐私与 Local-First 本地离线主义者**：坚决排斥将个人藏书、阅读偏好及私密笔记上传至中心化云端服务器或第三方大模型平台。要求 100% 本地运行、IndexedDB 数据库持久化，并通过 `.aurabackup` 离线自主备份在多台设备间无损迁移。
- **专注沉浸式思考者**：拒绝繁杂喧闹的 AI 幻觉生成弹窗与过度工程化干扰，需要纯粹的文字排版、精准的双色色彩语义（黄色标注事实/绿色承载思考），以及召回自如的无干扰全屏阅读界面。

## 2. 输入是什么？ (Inputs)

### 2.1 文件与内容输入
- **本地电子书文件**：
  - `.epub` / `.equb` / `.zip` 标准 EPUB 2/3 二进制电子书包（JSZip 自动解压，智能解析 `content.opf` 元数据与 `toc.ncx` 132 条规范目录，自动完成相对路径图片及 SVG 矢量的 Base64 内联转换）；
  - `.txt` 纯文本文件（智能段落识别与分章节排版）；
  - `.pdf` 文档格式（格式兼容标识解析与示例展示）；
  - 系统内置示例电子书（如《危机时代》、《深度工作》），支持免上传一键快速载入。
- **本地迁移备份文件**：
  - `.aurabackup` / `.json` 结构化全量离线备份包（含选中图书原件数据、划线随笔集合、阅读排版偏好配置，跨浏览器与跨机器无缝导入）。

### 2.2 用户交互与配置输入
- **文本划选与标注交互**：
  - **选中文本区域**：在主画布或双页对开辅画布上划选连续文本（支持跨段落、跨标签、跨标点选区），触发微型浮动 Tooltip（高亮 🟨、笔记 ✍️）；
  - **高亮点击交互**：点击正文中已高亮文本，触发浮动操作气泡（“写随笔” / “移除”）；
  - **随笔内容输入**：在 Modal 随笔弹窗中输入或修改思考感悟（支持 Markdown 语法与多行文本）；
  - **笔记区独立速记随笔**：在笔记区顶部快捷随笔框中即时速记读书感悟，无需划词直接保存至当前章节/页码；
  - **笔记卡片原地编辑**：在右侧笔记卡片点击【编辑】按钮，调出原选文与当前随笔进行原地更新。
- **阅读布局与视口交互**：
  - **单页 / 双页（Spread 对开）模式切换**：点击工具栏按钮或键盘快捷键 `D`；
  - **笔记侧边栏展开 / 收起**：工具栏按钮、侧栏内置收起按钮、极简微型“召回把手”、双击工作台分割条、或键盘快捷键 `B`；
  - **75:25 黄金分割拖拽调整**：25% ~ 85% 弹性 Clamp 分割比例调整；
  - **翻页交互**：上一页 `←` / 下一页 `→`（单页步进 ±1，双页步进 ±2，键盘快捷键与工具栏按钮联动）；
  - **全屏阅读切换**：点击工具栏全屏按钮切换浏览器全屏/退出全屏；
  - **示范图书切换**：点击工具栏“示例图书”按钮在内置经典图书间即时切换；
  - **目录导航**：点击目录抽屉中的 NCX 132 条章节条目或书内内嵌链接平滑跳转至对应章节与锚点。
- **阅读偏好与排版定制**：
  - **首行缩进模式切换**：`0em` 无缩进 / `2em` 2字标准缩进 / `3em` 3字大缩进；
  - **字体选择**：'Noto Serif SC' 衬线宋体 / 'Inter' 无衬线黑体 / system-ui 系统默认；
  - **字号调节**：12px - 32px 动态缩放（默认 18px）；
  - **纸张主题切换**：纯白 `white` / 护眼羊皮纸 `sepia` / 夜间墨黑 `dark`，及应用程序暗黑主题切换；
  - **纯划线显示过滤开关**：“显示划线 (N)”切换是否在侧栏混排纯划线卡片。
- **备份与迁移交互**：
  - 选择性备份弹窗交互（多书复选列表勾选、全选、取消全选、包含笔记复选框、包含排版偏好复选框）。
- **快捷键安全互锁规则**：
  - 当光标处于输入框、文本域（`<input>`, `<textarea>`）或处于编辑状态，以及当模态对话框处于激活展示时，全局翻页与布局快捷键（`D`, `B`, `←`, `→`）自动静默互锁，防止文字录入冲突。

## 3. 输出是什么？ (Outputs)

### 3.1 界面交互输出
- **75:25 黄金比例弹性工作台**：
  - **阅读画布区 (默认 75%，侧栏折叠时 100%)**：
    - **单页视图**：居中仿真实体纸张排版，舒适字距行距；
    - **双页对开视图 (Spread)**：左右对称排布的主画布与辅画布，中央呈现拟真立体书脊中缝阴影，视觉高度拟真实体典藏书籍；
    - **760px 临界自适应降级与自动恢复**：当阅读视口可用宽度 < 760px（如小屏幕、窗口缩窄或侧边栏展开挤占）时，系统自动非破坏性降级为单页模式，工具栏显示降级提示状态；当可用宽度重新 ≥ 760px（如扩大窗口或收起侧边栏）时，自动无感恢复双页对开展开；
    - **侧边栏折叠与微型召回把手**：当收起笔记侧边栏时，阅读区平滑扩展至 100% 视口，右侧边缘浮现微型极简“召回把手”（带防旋转竖排文本与图标，点击或按 `B` 瞬时恢复侧边栏）；
    - **4 种正交布局组合**：
      1. 单页模式 + 侧边栏展开（标准研读）
      2. 单页模式 + 侧边栏收起（专注单页宽幅阅读）
      3. 双页模式 + 侧边栏展开（宽屏对开研读）
      4. 双页模式 + 侧边栏收起（极致沉浸双页书卷阅览）
    - **偶数页位置保真**：在双页模式下翻至偶数页（如第 4 页），切换至单页模式时视口严格保留在第 4 页，绝不错误跳回第 3 页。

  - **笔记与控制面板区 (25%)**：
    - 双标签页结构：Tab 1 划线与随笔；Tab 2 设置与导出；
    - **双色正交卡片展示**：
      - 纯划线卡片：琥珀黄色边框与高亮徽章，标注为黄色划线；
      - 随笔感悟卡片：翡翠绿色边框与思考徽章，突出展示引文与 `💭 随笔思考`；
    - 原地【编辑】按钮与【删除】按钮；
    - “显示划线 (N)”过滤切换：默认模式仅展示随笔思考，避免高频纯划线淹没思考；点击切换后展示包含纯划线的全量卡片；
    - 快速独立随笔输入框（支持 Markdown 语法即时速记，无须划选正文即可记录）；
    - 点击卡片标题或引文，左侧正文平滑滚动聚焦并闪烁高亮对应位置。
  - **抽屉与弹窗**：
    - **“我的书库”离线 Drawer 抽屉**：展示 IndexedDB 中永久入库的全部书籍网格卡片（书名、格式、章节数、已添加笔记数、一键打开阅读、一键安全移除）；

## 5. 哪些内容不能生成？要保存哪些记录？支持哪些格式？

### 5.1 哪些内容不能生成？ (Prohibited Output)
- 严禁在 Markdown / Zip 导出中生成重复的原文段落及 `💡 [划线随笔] 原文：“...”` 二次粘贴冗余文本；
- 严禁向外部服务器发起任何未经授权的联网请求（严禁 AI 总结接口调用、严禁中心化云端同步接口拉取）；
- 严禁生成破坏图书原版章节结构、破坏 HTML 标签闭合或存在 404 资源引用的脏数据；
- 严禁在双页模式下产生跨书笔记串线或将右页选区错误关联至左页页码；
- 严禁在编辑随笔或选区重叠时生成分裂重复的笔记卡片。

### 5.2 要保存哪些记录？ (Persistence Records)
- **IndexedDB (`AuraReaderDB` v1)**：
  - `books` 存储桶（Object Store）：主键 `id`，保存图书唯一 ID、标题、格式、解压后 HTML 页面内容数组（`pages`）、目录树结构（`toc`）、入库时间戳；
  - `notes` 存储桶（Object Store）：主键 `id`，索引 `bookId`，保存划线引文 `quote`、随笔感悟 `comment`、色彩分类 `color` ('yellow'|'green')、所属页码 `page`、章节名称 `chapter`、更新时间戳；
- **LocalStorage 客户端偏好记录**：
  - 单页/双页阅读模式偏好 (`aura_layout_mode`: 'single'|'double')；
  - 侧边栏折叠偏好 (`aura_sidebar_collapsed`: 'true'|'false')；
  - 工作台切分宽度百分比 (`aura_reader_width`: 25-85)；
  - 首行缩进偏好 (`aura_text_indent`: '0em'|'2em'|'3em')；
  - 阅读字号大小 (`aura_font_size`，如 '18px')；
  - 阅读字体系列 (`aura_font_family`)；
  - 纸张背景模式 (`aura_paper_theme`: 'white'|'sepia'|'dark')；
  - 应用程序暗黑/白天模式 (`aura_app_theme`: 'light'|'dark')；
  - 单书笔记临时备份 (`aura_notes_{bookId}`)；
- **防御性清理记录**：
  - 应用启动时自动检测并清除历史遗留的云同步与 AI 配置 Key（`aura_sync_secret`, `aura_sync_last_time`, `aura_api_key`）。

### 5.3 支持哪些格式？ (Supported Formats)
- **输入支持**：
  - 电子书：`.epub`、`.equb`、`.zip`、`.pdf`、`.txt`；
  - 备份迁移包：`.aurabackup`、`.json`；
- **导出支持**：
  - `📦 分章节 Zip 包 (.zip)`：分章节 Markdown 笔记包（纯净行内 `==高亮==` + `00_目录概览.md`）；
  - `🌐 双栏离线 HTML (.html)`：单文件自适应双栏离线带标注电子书；
  - `📝 笔记摘要 Markdown (.md)`：全书划线与随笔摘要汇编；
  - `📊 结构化数据 JSON (.json)`：全书结构化标注数据；
  - `📥 迁移备份包 (.aurabackup)`：多书选择性全量持久化备份包。

## 6. 要做什么，不做什么？ (In Scope vs Out of Scope)

### 6.1 要做 (In Scope)
- 75:25 可拖拽弹性双栏阅读工作台（25%-85% Clamp 与双击快捷折叠/展开）；
- 单页 / 双页（Spread 对开）4 种正交布局组合，760px 宽度临界自适应降级与自动恢复，拟真书脊中缝立体阴影与微型召回把手；
- EPUB NCX 132 规范目录提取与平滑锚点跳转，图片 Base64 自动内联化与书内超链接拦截；
- 黄色纯划线（琥珀色卡片边框）与绿色随笔感悟（翡翠绿卡片边框）双色正交语义系统；
- 选中文本浮动 Tooltip（高亮/笔记）、已高亮文本浮动气泡（写随笔/移除）、笔记卡片原地编辑与智能色彩流转、选区重叠智能合并去重；
- 跨段落、跨多行及标点符号容错划选高亮匹配算法；
- 双页对开模式下右页选区页码（`P+1`）精准归属保真；
- 笔记区独立速记随笔输入框（支持 Markdown 语法速记，无需划选直接保存）；
- 笔记侧栏纯划线过滤切换开关（“显示划线 (N)”），默认专注呈现随笔感悟；
- 全屏沉浸式阅读模式切换与系统预设示例经典图书一键切换；
- 键盘快捷键与模态弹窗/输入框焦点安全互锁防御机制；
- 首行缩进（`0em`/`2em`/`3em`）、字体选择、字号缩放、纸张主题、暗黑模式切换与持久化；
- IndexedDB 本地书房数据库与“我的书库”管理抽屉；
- 5 大导出阵列：Markdown 摘要、JSON 数据、分章节 Zip 包、双栏离线 HTML、以及 `.aurabackup` 多书复选框选择性全量备份与一键还原；
- 彻底移除 AI 模块与云同步，100% Local-First 纯本地隐私安全离线运行。

### 6.2 不要做 (Out of Scope)
- 复杂的跨设备中心化服务器云同步（坚持 100% Local-First 本地存储与 `.aurabackup` 离线自主数据迁移）；
- 外部云端大模型接口与 AI 自动归纳生成（坚守纯净、无网络依赖、沉浸式人工精读与思考）；
- 手写自由笔迹与矢量涂鸦画笔（专注于排版文本流高亮与结构化随笔）；
- 多人实时在线协同阅读与社交评论；
- 侵入式服务端数据库托管（坚决保持纯前端无状态静态托管体系）。
