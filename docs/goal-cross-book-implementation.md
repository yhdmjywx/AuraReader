# 跨书 Goal 与独立页面实现记录

2026-10-26。基线为 `89defc4`，按 [获批实施计划](goal-cross-book-sidebar-plan.md) 完成。Goal 继续作为现有应用内的模块，复用原树、原位编辑器、标注与笔记操作，以及存储队列和备份入口。

## 用户可见结果

- 切换书籍保留选中 Goal、树与材料展开状态。两本书的高亮和笔记可以归入同一个 Goal，归入后立即展开；跨书材料显示简短书名。
- 顶部 `Goals` 进入独立页面。该页面只有一个 Goal 渲染器和编辑器，没有左侧 Goal 侧栏、分隔条或重复详情。目录与侧栏开关隐藏；窄窗、双页偏好、未打开书时仍可使用。
- 阅读侧栏保留默认 280px、220–640px 调宽及键盘操作，使用独立图标收放。页面切换不改写收放或宽度偏好，返回阅读保留原位置。
- 独立页面显示所有直接子 Goal；阅读侧栏的章节关联同时核对书籍和章节，避免不同书的同一章节号混淆。
- 点击材料调用原文定位；跨书时先打开明确来源，连续点击只保留最后有效导航，普通切书可取消待处理的来源跳转。没有新增引用面板或笔记编辑按钮。
- 删除原标注或书籍只清理对应材料链接，保留 Goal 文字与树。

## 代码与数据

| 改动 | 复用与边界 |
| --- | --- |
| `GoalController` / `GoalUI` | 全局状态在启动时载入；一个 DOM 根节点在侧栏 host 与 Goal 页面 host 之间挂载，复用原编辑器、父子树及材料列表 |
| `AppCoordinator` / `main` | 原切书流程保留书内 annotations；Goal 单独查询跨书材料。增加来源导航请求校验，隐藏阅读区不触发宽度 0 的重排 |
| `goalLibraryRepository` | 沿用串行队列、revision、幂等命令和本地恢复缓冲；独立保留全局 Goal 草稿、未确认操作与选中偏好 |
| `goalLibrary.js` / DataStore | SQLite v3 新增单行全局 Goal 表，原书籍和标注 JSON 不重写，旧 `goal_states` 表保留用于兼容；HTTP 与桌面 IPC 共用校验和事务 |
| 备份适配 | 原导入导出菜单、每书文件和标注选项保留，仅将 Goal 附加数据扩展为 1.2 全局图 |

旧 v2 Goal 使用 `(bookId, goalId)` 的稳定哈希转换 ID 和父节点引用，避免不同书重名 ID 碰撞。旧根节点记录原书来源，没有原位置时保留空页码。迁移校验旧树与来源后在事务内提交；失败保留 v2 数据及版本，不建立空全局库替代。

旧已发送命令按原 opId、revision 与 generation 重放。后续未发送快照仅在前序确认后更新 revision；旧草稿转换父节点 ID，直到全局写入确认才清理旧缓冲。冲突、旧来源 generation 和保存失败保留输入，关闭握手覆盖全局 Goal。

## 备份覆盖

每书 `.aurabackup` 1.2 包含与本书来源／材料有关的完整根 Goal 树，以及仅指向本文件标注的链接。恢复按全局 ID 合并节点，仅替换文件覆盖的书籍／节点链接，保留其他书的关联；恢复后同步当前 Goal 控制器，避免后续保存覆盖导入内容。取消包含标注时省略 links，缺失字段不表示清空。兼容旧 1.0/1.1。

完全没有书籍来源和材料关联的独立 Goal，由现有 SQLite 一致性备份覆盖，不附带到任意每书文件。本阶段没有新增 Goal 导出菜单。章节 Markdown、摘要、EPUB/TXT 解析和原标注／笔记编辑逻辑未扩展。
