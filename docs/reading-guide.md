# 阅读、Goal 与导出

从 README 迁入的使用与交互说明。Goal 完全可选；产品原则见 [PRD](prd_v0_5.md#1-产品定位与目标读者)。

![AuraReader 双页阅读、高亮与沉浸式页边笔记](../src/client/assets/screenshots/reader.png)

双页阅读、高亮与沉浸式页边笔记（《巴黎圣母院》示例）。

## 基本使用

1. 点击左上角 AuraReader 标识进入 Library，导入 EPUB 或 TXT，再打开书籍。可以直接阅读，也可以先建立 Goal 并关联书籍；不要求设置 Goal。
2. 点击书名旁的目录入口跳转章节，使用底部分页导航阅读。
3. 在正文中选择文字，添加划线或笔记；在页边笔记区查看、编辑及定位原文。
4. 点击顶部界面选项图标调整阅读设置。选择字体后立即应用；“更多字体”可读取本机字体、搜索或导入本地字体文件。
5. 点击顶部全屏按钮前的“导出与备份”图标，选择导出格式、导出书籍备份，或导入恢复备份。

| 快捷键 | 操作 |
| --- | --- |
| `D` | 切换单页／双页 |
| `←` / `→` | 上一页／下一页 |

输入文字或打开对话框时，阅读快捷键会受到互锁保护。

## 能力与交互细节

- **阅读 Goal**：写下自己的目标、问题或期待，按文件夹方式逐层进入 Goal；Home 图标回到根层级，上箭头返回上一级，＋在当前层级新建并留在原处。根层级只列顶层 Goal，进入后显示直接子 Goal 及相关材料，切书／换章节不会隐藏子 Goal。Goal 独立于书籍；切书保留当前 Goal 与材料展开状态。单页左侧栏宽度为 220–640px，支持拖拽、方向键、Home/End、双击复位及偏好保存。侧栏放大图标进入独立 Goal 页面，收起图标返回阅读；不再提供顶部 Goals 按钮或 All goals / Current goal 切换。点击 Goal 文字原位编辑，没有分类步骤。笔记原操作区与高亮原浮条中的 `Goal` 按钮将材料归入当前 Goal；归入或重新进入后自动展开摘录。跨书材料显示来源书名，点击沿用原阅读定位，`×` 只解除关联。返回阅读保留原位置及侧栏偏好。
- **沉浸式页边笔记**：在正文中选择文字即可添加高亮或笔记。高亮保留在正文中，笔记直接显示在对应原文外侧，不需要展开侧栏。笔记区只显示你的笔记内容，原文引用仍保留在编辑和导出中；点击笔记可以定位原文，也可直接编辑、删除。
- **按 Goal 浏览书库**：点击左上角 AuraReader 标识进入 Library，根层级显示顶层 Goal 和全部书籍；进入 Goal 后显示直接子 Goal 及其关联的书籍卡片，点击书籍直接阅读。Home、上一级及路径支持逐层导航，＋在当前层级创建 Goal，书本＋添加已有书籍或导入新书。浏览和新建不改变正在阅读的 Goal，从 Goal 中开书才切换阅读意图；继续阅读按钮保留原意图。同一本书可服务多个 Goal，子 Goal 不复制父级书单，移除关联保留书籍。首次空库可先创建 Goal 或直接导入。原 Goal 页面和阅读侧栏不增加书单。见 [实现与验收](goal-books-implementation.md)。
- **跟随当前屏幕**：默认只显示与当前可见正文相交的笔记，双页包含左右两页。跨页引用只要仍有一部分原文可见，就保留该笔记；翻页、滚动或调整排版后自动更新。不再新建无原文引用的独立随笔，已有数据仍保留在存储和备份中。
- **两种主要导出方式**：
  - 想保留书籍内容并在 AuraReader 中备份、恢复，选择 **“导出书籍备份”（`.aurabackup`）**。每本书生成一个备份文件，包含书籍正文、目录以及高亮和笔记。
  - 想保存为 Markdown、放入知识库或直接提供给 AI，选择 **“按章节导出”（`.md`）**。菜单原位展开“当前章节／全部章节／选择章节”，前两项直接保存，自选时才展开章节列表，不遮挡阅读界面。高亮保留为 `<mark>原文</mark>`；笔记附准确原文引用，并放在对应段落之后。
  - **单章保存为 `.md`，多章选择位置后新建“书名_章节导出”文件夹**，内含各章 Markdown 和 `00_目录概览.md`，保留原章节编号；同名文件夹自动加序号，不覆盖已有导出。纯卷标题随对应首章保留，同篇正文的多个目录项一并导出。HTML 导出已废弃。
  - 桌面端使用系统文件／目录选择器；网页版多章导出需要浏览器提供文件夹保存能力，不支持时会提示使用桌面版，不自动改为 ZIP。

  下图左侧展示了书籍在 AuraReader 中的单页阅读与页边笔记效果，右侧展示了同一章节导出 Markdown 后在 VS Code 中的预览效果，也可在 Obsidian 等支持 Markdown 的编辑器中使用。若希望保留为可在 AuraReader 中恢复的电子书备份，选择 `.aurabackup`；若只想导出笔记摘要，也可以单独选择 **“笔记摘要”（`.md`）**。页边笔记的筛选不影响全书导出与备份。

  ![左侧为 AuraReader 单页阅读与页边笔记，右侧为分章节 Markdown 在 VS Code 中的预览](../src/client/assets/screenshots/markdown-export.png)

- **阅读与导航**：导入 EPUB、TXT，使用书库和目录打开书籍、跳转章节；支持单页、双页及连续滚动阅读，笔记直接显示在正文旁。
- **简洁排版**：正文与页边笔记共享阅读背景，没有侧栏分界线、卡片边框或展开操作。双页每栏保持 560px、栏间距 72px；笔记按窗口空间排列在两侧、右侧或底部，不挤压双页行宽。窗口不足以容纳完整双页时，自动暂用单页。
- **字体设置**：默认按书籍语言自动选择字体；内置更纱黑体和 Literata，正文精选字体随应用分发，离线可用。通过“更多字体”搜索本机字体，或导入 TTF、OTF、WOFF2。字体偏好对所有书籍生效。
- **其他阅读设置**：字号、首行缩进、阅读背景、单页／双页版式、界面明暗及全屏。

> 历史导出说明：带标注 HTML 和章节 ZIP 曾用于旧版本及桌面阶段验收；当前导出菜单不再提供 HTML，按章节导出使用 Markdown／文件夹，不自动回退 ZIP。历史能力与证据保留在各 Electron 阶段记录中。

## Goal 生命周期

当前源码还支持完成／重新开启、归档／恢复、最近删除及逐条恢复或永久删除。归档或删除当前意图后保留正在阅读的书籍与位置；永久删除 Goal 不删除原始书籍、高亮或笔记。最近删除的批量清空尚未实现，安装包也未据此重新验收。交互与证据见 [生命周期验证记录](goal-lifecycle-verification-2026-10-27.md)。
