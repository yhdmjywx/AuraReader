# Goal UI 渐进优化指导

2026-10-26。功能基线：`7921c3e`。第 1 轮静态层次已实施并验收；第 2–4 轮动效与局部反馈仍为后续建议。

用户反馈整体可视性不足后，已优先完成 [Goal 可视性与操作可辨识改进方案](goal-visibility-improvement-plan.md)，提高对比度、字号和按钮尺寸，使核心操作常驻；具体验收见方案文末。后续可继续下文动效阶段。

## 贯穿各轮的方向

应用背景承载导航和 Goal 侧栏，阅读正文与页边笔记组成一块主要内容表面；独立 Goal 页面也是主要内容表面。Goal 的数据与书籍独立，视觉上仍允许阅读成为阅读场景中的焦点。

用背景、留白和轻微深度表达区域关系。用动效解释刚发生的变化。圆角属于内容容器，阴影表达表面层次；避免给每条 Goal、材料和笔记增加卡片外壳。

截图中的 Codex 提供的是表面边缘的视觉参考；不能由截图推断其内部布局或动画实现。以下像素值和时长是 AuraReader 第一轮试验起点，不是 Apple 或 Codex 的规定。

## 四轮推进

| 轮次 | 具体改动 | 用户体验时判断什么 |
| --- | --- | --- |
| 1. 静态层次 | 减弱或移除 Goal 侧栏贯穿全高的右边框；阅读内容容器先试 12px 圆角、顶部／右侧／底部 8px 留白和非常轻的阴影。拖动热区保留，仅 hover、键盘聚焦和拖动时显示提示。Goal 主区沿用同一表面语言 | 不操作时，能否自然看懂侧栏与内容区域；暗色、羊皮纸、宽侧栏时是否仍协调；正文与页边笔记是否仍是一组 |
| 2. 侧栏收放 | 从左侧连续揭示／收回，开约 200ms、关约 160ms，平顺减速。书籍容器边缘同步变化；拖宽直接跟手，不使用缓动追赶指针。允许连续点击时反向或结束到最新状态 | 能否理解侧栏去了哪里；正文是否跳字、跳页或失去锚点；快速连续操作是否流畅且结果正确 |
| 3. Goal 页面进退 | 使用约 120–180ms 的短过渡切换阅读与 Goal 工作区，优先淡出／淡入，必要时只给新内容 4–8px 位移。顶部导航作为稳定参照。保留一个 Goal DOM 和编辑器 | 是否感到切换到一个独立工作区；是否仍记得原来的书；返回后位置与宽度是否恢复；是否出现重复 Goal、空白闪烁或焦点丢失 |
| 4. 局部反馈与一致性 | hover／按下反馈约 100–120ms；新归入的材料出现一次短淡入，已有材料不重复播放；统一控件圆角、焦点样式和两种页面的间距关系 | 是否更容易确认操作成功，同时不拖慢连续归入和编辑；鼠标、键盘和减少动态效果设置下是否都清楚 |

每轮只改变一类问题，并保留上一轮截图和代码检查点。第一轮只判断静态层次；静态关系成立后，再用动画连接这些状态。

## 落地到当前代码的注意点

- 当前 `.goal-sidebar` 的 `border-right` 是硬分界来源。`#workspace-container` 包含正文与页边笔记，优先在其外围表达内容表面；不只给书页本身加圆角，也不把笔记另包成浮动面板。
- 圆角和留白会改变可用宽度。沿用现有宽度计算并核对正文、页边笔记及窄窗阈值，不通过缩小正文、放大阴影或隐藏笔记掩盖空间问题。必要时以独立背景层绘制边缘，避免新增裁剪损坏浮条与焦点轮廓。
- 当前收放依靠 `hidden`；仅添加 `transition: all` 无法得到可靠的进入／退出动画。后续只在展示代码内协调过渡与最终隐藏状态，保留原来的保存确认、关闭偏好和一套 DOM。
- 当前 `ResizeObserver` 会触发阅读区 refit。宽度逐帧变化可能导致正文反复重排；试验时要比较稳定布局配合视觉过渡的方案。不能以缩放正文制造顺滑感，也不能在动画中牺牲选区、页边笔记位置和阅读锚点。
- 页面切换不能动画结束才执行存储或导航。编辑仍先按原流程可靠保存；动画期间的新操作指向最新目标，旧过渡不得把界面切回过期状态。
- 统一定义少量视觉变量：内容圆角、外沿间距、表面阴影、短反馈时长、工作区切换时长和减速曲线。暗色通过边缘／背景层次补足分离，不机械增大黑色阴影。
- 尊重系统 `prefers-reduced-motion`：减少或取消位移，直接切换或使用短淡入；功能和反馈信息仍完整。

## 第一轮的执行指令

> 只优化应用背景、Goal 侧栏与阅读内容容器的静态层次。弱化贯穿分界线，试验小幅留白、12px 内容圆角和轻阴影；保留侧栏拖动热区及焦点提示。正文与页边笔记保持一组，不增加卡片或文案。核对亮／暗主题、羊皮纸、侧栏 280／640px、窄窗、单双页与浮条可见性。暂不加入动画，也不改 Goal、标注、笔记或备份逻辑。

## 第一轮实施与验收结果

- 阅读内容容器及独立 Goal 页面统一使用 12px 圆角、8px 外沿留白和轻阴影。暗色主题使用低强度亮边辅助分离；正文和页边笔记共用一个表面，未引入逐条卡片。
- 移除 Goal 侧栏右侧常驻实线。8px 拖动热区及键盘聚焦保留，边界提示仅在悬停、聚焦或拖动时出现。
- `goalLayout.ts` 按实际外沿留白计算剩余空间，继续为阅读保留至少 720px；窗口临时变窄不覆盖用户的侧栏宽度偏好。正文排版及笔记定位算法保持原实现。
- 构建和类型检查通过；`npm test` 共 59 项通过、0 失败。真实 Electron 桌面回归通过，包含笔记编辑、高亮原浮条、侧栏拖宽与编辑器光标、页面去重、跨书定位和返回阅读位置。
- 已检查亮／暗主题、羊皮纸、280／640px 侧栏、800px 窄窗及可用空间足够时的双页截图。桌面报告及截图位于 `.commandcode/desktop-tests/run-gkk21V/`，回归日志为 `.commandcode/goal-surface-tests.log`。
- 本轮未实施第 2–4 轮动画，未修改数据、备份或材料归入规则。

## 参考依据

- [Apple HIG — Materials](https://developer.apple.com/design/human-interface-guidelines/materials)：材质与表面帮助表达深度、层次和前后关系。本文据此建议先确立层次，具体圆角、留白和阴影由 AuraReader 试验决定。
- [Apple HIG — Motion](https://developer.apple.com/design/human-interface-guidelines/motion)：动效应有目的、简短、可取消，方向符合交互预期；频繁操作避免额外等待。
- [MDN — prefers-reduced-motion](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion)：通过媒体查询尊重系统减少动态效果偏好。
