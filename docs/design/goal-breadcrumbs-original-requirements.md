# Goal 层级导航初始需求

记录日期：2026-11-04。

最初的改造需求是：**Goal 区目前只能看到当前父 Goal 和子 Goal，缺少完整层级的位置感，需要一种按需查看和进入其他层级的方式。**

完整大纲不常驻。平时继续围绕当前 Goal 阅读和思考；需要了解整体结构时，再通过入口唤出。这个入口最初可以采用路径、悬停展示或拆分展示，文件夹路径只是可参考的方式。

随后确定采用 **VS Code Breadcrumbs** 作为方案，并明确交互：**点击路径文字直接进入，悬停文字打开可操作的选择器；选择器里的 Goal 可以点击进入，分支可以展开。路径旁不要独立下拉按钮。**

后续对选择器内容的明确纠正是：**悬停某个 Goal 应展示它的子内容，不展示它自身所在的同级列表。**

这项改造始终围绕：**保留现有 Goal 工作区，补足层级位置和按需导航。**
