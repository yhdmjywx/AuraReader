# Goal 创建与选书：实现和桌面验收

2026-10-26。初版按用户要求增加独立新首页，保留既有 Goal 主页面与阅读侧栏的 UI/UX。随后按用户新的手测反馈统一 Goal 导航，最新规则见下节。

## Home 的最终职责：按 Goal 打开书籍

用户进一步明确 Home 用来打开书籍，以 Goal 组织。本阶段只重设计独立首页，原 Goal 主区及阅读侧栏继续使用已验收的文件夹式交互。

- 首页进入 Library 根层级，展示顶层 Goal 入口和全部书籍；无 Goal 也能打开书籍。
- 进入 Goal 后展示直接子 Goal 和它主动添加的书籍卡片；没有继承书单或隐式书籍关联。
- 使用 Home、上一级及祖先路径导航；不使用平铺 Goal 下拉选择器。窄屏保留导航图标，隐藏拥挤的路径文字。
- 书籍卡片为主要点击目标，显示书名和文件格式；点击直接阅读，不再有“查看 Goal”的中转。书本＋打开选书列表，解除关联用独立图标，不删除书籍。
- 新建后留在当前层级。浏览及新建不会替换当前阅读意图；从 Goal 开书时才选择它，继续阅读保留原意图，从根层级开书则不偷偷沿用旧 Goal。
- 导入与关联复用原解析、队列和恢复缓冲。关联失败后重试成功会收起选书列表并显示已保存的卡片。

## 手测反馈后的导航修订

- 移除顶部 `Goals` 按钮；侧栏右上角放大图标进入 Goal 主界面，主界面收起图标返回原阅读。
- Home 图标回到根层级，只列顶层 Goal；上箭头返回上一级；点击列表项进入 Goal，显示直接子 Goal 和原有材料。
- 不再提供 `All goals` / `Current goal` 状态切换、分支展开箭头或单独的 `Subgoal` 按钮。
- 唯一的新建图标在当前层级创建。提交后留在该层级，点击新条目才进入；编辑时连续点新建也产生同级条目，不意外深入。根层级不关联到上一次选中的 Goal。
- 所有直接子 Goal 持续可见，不再按当前书籍／章节筛掉目录内容。书籍来源、材料关系和备份字段不变。
- 阅读首页的新建也以当前显示的 Goal 为父节点；首次创建以根层级为父节点。待恢复草稿记录创建时的父节点，避免后续选择改变写入位置。

## 用户行为

- 首次空库进入 `Reading home`，可 `Create a goal` 或 `Import a book`。不强制创建 Goal，不自动插入示例书。
- 左上角 AuraReader 标识外观不变；点击、Enter 或 Space 返回首页。有当前书籍时可 `Continue reading`。
- 首页选择 Goal 后，`Add book` 可添加已有书籍或导入 EPUB/TXT。书单立即更新；添加本身不强制开书，点击书名才进入原阅读界面。
- 同一本书可服务多个 Goal；`Remove` 仅解除书籍关联。
- 子 Goal 沿用当前阅读，不复制父级书单。选书时优先提供当前书、当前及父级 Goal 的主动书籍关系和材料来源，然后提供其余书库。
- `View goal` 进入原 Goal 页面；首页不复制 Goal 树、材料列表或笔记编辑器。

## 接入与数据

`src/client/features/goals/goalHome.ts` 承载新界面；`main.ts` 只装配入口和界面切换，`AppCoordinator` 复用原导入解析及开书流程。首页离开时保留既有阅读状态，普通开书与原文跳转仍走原请求顺序控制。

全局 Goal JSON 增加 `bookLinks: {goalId, bookId, generation}[]`，复用原 revision、幂等命令和串行保存队列；没有增加关系表、独立书库或通用路由。数据库版本为 4。旧命令缺少该字段时保留已有书籍关系。删除书籍时在同一事务清理关联，删除笔记不影响主动添加的书籍。

每书 `.aurabackup` 升至 1.3，包含该书的主动关系及相关 Goal 根树，即使取消包含高亮／笔记也保留书籍关系。旧文件缺字段不清空已有关系；逐书恢复保留其他书籍关系，按目标书籍代次绑定。没有任何书籍或材料来源的独立 Goal 仍由 SQLite 一致性备份覆盖。

新首页草稿保存在原有本地存储环境中，以稳定 ID 恢复；成功创建后移除草稿。先保存书籍、再建立关联；若后一步失败，`aura_goal_book_pending` 保留目标和代次，重试只补关联。关闭窗口先等待正在进行的操作并保存草稿，再走原关闭保存流程。
