# 紧凑顶栏与目录浮层需求

2026-11-19 设计定稿，已接入 Web 和 Windows 桌面源码。构建和验收结果见 [代码设计与验证](architecture.md)。

## 目标与范围

让读者一打开材料就能找到目录、翻页和常用工具。将工作区顶部的书籍操作收进一条常驻短栏，让目录每次在同一入口下方展开。Windows 桌面版把窗口按钮放在同一高度。

## 紧凑顶栏

- 短栏随内容收窄，放在正文区域上方并水平居中。它在鼠标离开时仍可见。Goal 侧栏开合时，短栏随正文区域定位。
- 从左到右显示 `Contents`、当前书名、上一页／当前位置和总数／下一页、书库、阅读设置、导出。`Contents` 使用目录图标和文字。书名过长时单行省略，完整书名仍可查看。翻页、书库、阅读设置与导出复用现有动作和数据。
- 选中或展开时用较深的图标和浅底提示状态。图标可以轻微放大，按钮点击范围和相邻元素保持原位。键盘焦点应清晰可见。

## 目录浮层

- 用顶栏的 `Contents` 统一开合目录。展开时按钮保持高亮。浮层直接显示章节列表，顶栏入口使用图标和文字，浮层内移除重复的 `Contents` 标题和 `×` 按钮。
- 浮层始终紧贴在 `Contents` 所在短栏的下方，**面板外框左缘与短栏外框左缘对齐**。首条章节使用面板内边距，具体间距以定稿为准。调整正文行宽、窗口宽度或 Goal 侧栏时，浮层跟随短栏的位置。
- 浮层可以临时覆盖部分正文。仅开合目录时，正文行宽、阅读位置和分页保持稳定，目录滚动在浮层内进行。空间较小时，限制浮层高度以保证列表可滚动。
- 章节名称、层级缩进和可导航条目的页码使用当前书籍的目录数据。点击章节沿用现有定位与收起行为。再次点击 `Contents` 或点击浮层外可收起。键盘可操作入口和章节，收起时保留合理的焦点位置。

## Windows 桌面窗口按钮

- 在窗口右上角同一行放置最小化、最大化／还原、关闭。窗口按钮不额外占用一条横栏，并与短栏保持足够间距。顶部空白保留窗口拖动区域。
- 窗口按钮执行系统窗口动作。关闭继续使用现有的保存和关闭流程。浏览器版由浏览器提供窗口控制。

## 验收

| 场景 | 预期结果 |
| --- | --- |
| 打开书籍，鼠标离开顶部 | 短栏保持可见。书名、翻页状态和各操作显示正确。 |
| 用鼠标或键盘打开目录 | `Contents` 高亮，目录直接显示在短栏下方，两个外框左缘对齐。列表直接从章节开始。 |
| 调整正文行宽、窗口宽度，或开合 Goal 侧栏 | 目录随短栏定位。长目录可在浮层内滚动。单独开合目录时，正文位置、行宽和分页稳定。 |
| 选择章节、再次点击 `Contents` 或点击浮层外 | 章节跳转及收起行为正确，收起后入口可继续操作。 |
| 操作翻页、书库、阅读设置和导出 | 原有入口对应的功能可用，翻页信息随阅读位置更新。 |
| 在 Windows 桌面操作三个窗口按钮 | 最小化、最大化／还原和关闭均可用。窗口最大化与恢复后按钮仍在右上角，关闭沿用现有保存流程。 |

## 现行沉浸式阅读界面

书名与翻页在阅读区顶部居中，顶栏融入纸面。目录、书库和阅读设置以图标排列在阅读区右侧中部。入口默认使用中性的灰色，浮层展开时使用强调色和浅色底。三个浮层统一向左展开，宽度为 210 px，共用工具组的纵向中线。浮层随内容增高，最高 360 px，且不超过阅读区高度减 16 px。超出部分在浮层内滚动。

目录隐藏滚动条。下方还有章节时，列表底部显示 16 px 的纸面同色渐变提示。短目录和已滚到底的目录不显示渐变。滚轮、触控板及键盘导航继续可用。

书库浮层从搜索和书籍列表开始。列表隐藏滚动条，下方还有书籍时显示 16 px 的纸面同色渐变，滚到底或内容无需滚动时隐藏渐变。导入图标居中固定在渐变下方的纯色区域，沿用书库首页图标及现有文件选择流程，悬停提示为 `Import book`。使用右侧书库入口、外部点击或 Escape 收起浮层。浮层保留无障碍名称。

浮层同一时间只开一个。再次点击入口、点击外部或按 Escape 可关闭。目录直接呈现可键盘导航的章节列表。开合浮层时保持正文行宽、阅读位置和分页。白色、米色和深色沿用现有 Paper 配色，Windows 窗口按钮与书名和翻页器处于同一高度。

阅读设置中的字号、行距和行宽采用分离式横向滑块。窄拨片位于左侧，右侧独立显示实时数值，保持 `px` 和 `×` 单位。键盘方向键可按步长调整。面板按内容高度显示，排版即时预览并保留阅读锚点。行宽继续受阅读区可用空间限制。

首行缩进沿用相同的滑块与右侧读数，提供 `0em`、`1em`、`2em`。没有保存偏好时默认显示 `1em`，EPUB 保留原书缩进直到用户调整。已有 `3em` 偏好按 `2em` 读取。

阅读时，从应用的 `Settings` 展开 `Export book`，显示当前书名和既有的 `Notes summary`、`Chapters` 导出选项。初次打开 Settings 和关闭后重新打开时，导出分组默认收起。

## 右侧阅读工具组分阶段方案

### 第一阶段 · 自动收起与原位唤出

保留现行 Figma 的三个入口、右侧纵向中线及向左浮层，以 [交互样稿](../../prototypes/reading-tools-lifecycle.html) 的 Tool stack（三格叠放）为收起态图标。`ReadingTools` 提供展开与收起的界面，工具组控制器按书籍 ID 在本次应用会话内维护状态。阅读器报告成功翻页、主动滚动的实际位移及章节选择。目录、书库和阅读设置继续使用各自现有的开合与操作逻辑。

| 场景 | 验收规则 |
| --- | --- |
| 打开新书 | 在阅读区右侧中部完整展示目录、书库、阅读设置。 |
| 分页阅读 | 首次主动翻页成功后等待 10 秒。首次收起前，每次成功翻页都从该次翻页重新计时。 |
| 连续滚动 | 主动滚动累计约半屏后，从最后一次实际滚动开始等待 10 秒。首次收起前，继续滚动会重新计时。 |
| 使用工具 | 指针在工具区或浮层内、键盘焦点在其中，或浮层仍打开时保持展开。工具与浮层之间可直接移入。 |
| 收起与再次使用 | 三个工具以短动画收成原位的一个三格叠放图标。悬停、点击或键盘聚焦可唤出。首次收起后，离开整个区域时短暂延迟收回，按 Escape 或选择章节也可收回。 |
| 离开后切回同一本书 | 保留本次会话中该书的工具状态。目录跳转沿用该书已有状态。 |

### 第二阶段 · 目录图钉（草稿）

考虑在目录内提供图钉。钉住后，即使右侧工具组收起，目录入口也保留为可直接使用的入口，书库和阅读设置继续沿用第一阶段的展开和收起规则。目录浮层仍按需打开。待确认图钉的准确位置、固定后的排列及偏好的保存范围，再细化 Figma 状态和验收规则。
