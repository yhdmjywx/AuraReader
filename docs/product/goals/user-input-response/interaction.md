# Goal 用户自输入：交互约定与组件整合

日期：2026-11-10。

状态：依据用户三条批注、已选 02 稿及现行设计系统，完成原 Goal Sidebar 的模块整合、状态稿和局部状态切换连接。应用功能尚未实现。

## 1. 本轮用户确认

- 分支图标、叠层文档图标暂时仅作区域标识，不执行动作，不提供折叠。
- 自写内容为多条独立文字记录，每条允许换行。
- MVP 中，自写内容属于创建它的 Goal，不自动成为可跨 Goal 共享的原始标注。

以上确认补充[功能需求](feature-spec.md)，没有改变已有 Highlight、Note 可被多个 Goal 关联的关系。

## 2. 继承现有设计系统的交互

本轮用户指定以[设计系统](../../../design/design-system.md)作为 UX 来源。Goal 内的自写内容沿用同区 Goal 的原位编辑方式；删除操作复用现有笔记的明确删除动作，不新增生命周期系统。

| 场景 | 约定 |
| --- | --- |
| 新建 | 点击当前 Goal 内容区的“文档＋”，在已有内容之前出现一条原位草稿；已有内容仍保留。未进入具体 Goal 的根层级不提供自输入入口 |
| 多条记录 | 一次新增对应一条独立记录；记录内部可以换行，不将每段文字自动拆成另一条内容 |
| 输入 | 编辑器与显示文字保持相同原点、宽度和字体，随文字增高，不添加独立弹窗或常驻 Save/Cancel 区 |
| 换行与结束 | Enter 换行；失焦、Escape、Ctrl/Cmd+Enter 结束编辑并自动保存。Escape 不撤销已保存文字 |
| 中文输入 | IME 组合期间不因上述按键提前结束；实现时保持光标、选区与输入节点稳定，不触发正文翻页快捷键 |
| 空白新草稿 | 结束编辑时为空则丢弃，不生成空白记录 |
| 已有记录 | 编辑图标进入原位编辑；沿用 Goal 区对已有内容的保护：结束时清空不隐式删除，恢复最近非空内容。删除使用明确动作 |
| 行操作 | hover、键盘焦点或对应操作开启时显示编辑、删除；无 hover 的设备保持可访问。动作覆盖匹配的行背景，不因显示动作改变正文宽度；编辑中隐藏动作 |
| 删除 | 明确点击 Delete text，删除当前自写记录。参照现有笔记的直接删除方式，本轮未添加确认弹窗、回收站或新 Undo 机制；其他记录和来源标注不受影响 |
| 位置 | 新加入的记录在上；编辑既有记录不更新其加入顺序。Response 的已有 MVP 规则保持不变 |
| 保存失败 | 保留文字并显示持续可见、可关闭的错误反馈，提供 Retry。关闭反馈不表示保存成功，也不丢弃待保存内容 |
| Goal 切换或关闭 | 沿用现有结束编辑和保存检查；保存失败时保留输入，不将未确认写入当作可靠保存 |

页边笔记的“Enter 结束、Shift+Enter 换行”和红色自定义光标属于其局部例外，没有扩展到 Goal 自输入。

- [02 常态依据稿](https://www.figma.com/design/eib6b1sDBsFa7hTzY2Zmsi?node-id=265-1744)：保留，作为布局和字体依据。

| User Input State | 含义 |
| --- | --- |
| Default | 已保存文字的常态展示 |
| Hover | 编辑、删除行操作；同时作为键盘焦点时的操作外观参考 |
| New | 位于旧内容之前的空白草稿，显示 Write… 与输入光标 |
| Editing | 已有记录原位编辑，保留文字、类型图标与原文字位置 |
| Disabled | 暂不可操作状态，使用既有禁用外观 |
| Error | 文字保留，显示保存错误、Retry 和关闭反馈动作 |
| Deleted | 组件内的移除状态示意；实际实现须移除记录，不存一条 1px 高的空白记录。审阅页直接展示删除后的列表 |

原 Sidebar 的 Expanded、Editing parent、Editing child 保留对应 Goal 和材料实例，加入用户自输入；Root 保持无选中 Goal 的导航结构。原 Collapsed 变体节点 `14:316` 改为 Empty content：内容为空但新增入口可用，不再表示已取消的 Linked 分组折叠。其余原变体 ID 与全侧栏尺寸保留。

- 完成原组件结构检查、独立记录状态与共享属性检查，原五个 Sidebar 变体 ID 和外框尺寸保留。

- 状态审阅页包含 424 个可编辑节点，无图片填充或整页位图；完成整体截图检查，修正行操作覆盖区与错误反馈关闭动作。

- Figma 不执行真实键盘输入、IME、自动保存、删除或网络重试。相关行为是待实现约定，局部状态切换不构成应用功能测试。
