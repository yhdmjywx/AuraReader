# Wiki 功能

更新：2026-11-06。分支：`codex/wiki-feature`。MVP 与最新 Sidebar 设计已接入源码；构建、针对性检查和浏览器真实查询已验证。桌面退出及安装包验证仍有未完成项，见[实现与验证记录](implementation.md)。

应用已按 Figma 实现 337×341 Wiki Sidebar：固定于书籍右侧，横向位置复用笔记几何，查询词使用常驻灰色底线，菜单范围为简中、英、繁中、法、德、西班牙。内置浏览器已确认书籍实际滚动时面板坐标不变，详见[当前规格](feature-spec.md)及[验证记录](implementation.md)。

当前范围：原词查询、已有重定向、正文导言、手动切换当前词条已有语言版本、右上角原文箭头；原入口退出。不提取短语概念、不自动翻译、不做跨语言搜索或候选系统。

设计入口：[Wiki Sidebar，236:1614](https://www.figma.com/design/eib6b1sDBsFa7hTzY2Zmsi?node-id=236-1614)，是 `02 - Components` 下的独立主组件。原阅读 Screen 已恢复，右侧笔记区仅是运行时挂载规则。`198:1694` 仅为正文区域。
