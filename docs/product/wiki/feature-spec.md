## 1. 本期功能

用户选中文字并点击 Wiki 入口，在应用内查看该词条正文导言；可修改查询词，按 Enter 查询。语言选项只切换当前词条已有的其他语言版本。右上角 `↗` 打开当前版本完整原文，退出控件放在原入口处。

必要元素为查询词、正文、语言选项和原文箭头。加载、未找到和失败提示复用正文区域，不新增常驻功能面板。无需创建高亮、笔记或 Goal。

## 2. Figma 与界面约定

2026-11-05 经 Figma MCP metadata 核实以下节点；尺寸仅记录该实例，不是全局规则。本轮未做像素样式或原型交互验收。

| 元素 | 节点 | 设计记录／行为 |
| --- | --- | --- |
| Wikipedia Dialog | `194:1665` | 300 × 370，完整弹窗 |
| Local Library 底座实例 | `194:1595` | 只继承外观，不继承书库功能 |
| Search term | `198:1683` | 可编辑实际查询词，Enter 提交，无独立 Search 按钮 |
| Language selector | `200:869` | 显示当前语言，列出文章已有版本 |
| Frame 1 正文容器 | `198:1694` | 251 × 303，正文独立滚动，顶部不随正文滚动 |
| Body text | `198:1692` | 示例内容是占位，不是默认正文 |
| Original link ↗ | `210:821` | 右上角原文入口，不是关闭按钮 |

- 原入口负责退出，右上角不加关闭按钮。该入口的具体视觉状态未由此 Frame 覆盖，不另行发明位置或样式。
- 正文每段首行缩进两个字符宽度，后续行不缩进；使用正文范围内的 `text-indent: 2em`，不插空格或移动整个文本框。
- 不加独立词条标题行、原始选词回顾、其他结果入口、来源语言选择器或候选列表。
- 必要来源归属与许可信息仍须保留；复用原文链接，许可信息具体呈现未在此 Frame 定义，不扩展成常驻功能面板。
- 当前节点不证明下拉展开、失败、滚动和退出状态已做成可运行原型；实现时需验证。字体、颜色与其他样式按 Figma 及项目设计系统取值。

## 3. 原词查询

1. 从 reader 的纯数据快照复制选词，点击入口后才发请求。
2. 仅清理首尾空白，不剪词、提取概念、翻译、改写或自动选择近似结果。
3. 使用 Wikipedia 标题查询，接受维基已有的重定向和标题规范化。
4. 未找到时提示未找到，保留查询词供用户修改后 Enter 重查，不调用相关搜索或实体搜索。
5. “坚硬的蛋壳”就按完整文字查，不自动变成“蛋壳”；用户可自行修改。

命中消歧义页时提示包含多个含义，允许通过 `↗` 查看原站或手动改成具体词条名，不自动选词义、不构建候选系统。章节重定向保留章节地址，不把目标页导言冒充章节解释。文章存在但导言为空时提示不可预览，保留原文入口。

## 4. 手动切换词条语言版本

初次站点沿用简化后的实现默认：受支持的书籍语言 → 受支持的系统语言 → English。这只决定首次请求站点，不代表自动识别选词语言，不触发跨语言重查。中文地区标签统一映射中文 Wikipedia，简繁不当作两个百科站点。无单独源语言修正界面、无语言偏好持久化。

1. 先显示初始站点文章，如中文“蛋壳”先显示中文正文。
2. 获取该条目的官方 `langlinks`；在上述六个固定菜单项中启用真实关联版本，其他项禁用。简繁中文使用同一中文站点的显示变体。
3. 用户选择 English 后，用关联返回的英文标题读取英文文章；正文、当前语言和 `↗` 一起更新。
4. 不自动加载偏好的目标版本，不翻译选词或正文，不拿同一词盲查英文，不使用 Wikidata 实体搜索。
5. 没有其他站点版本时，对应菜单项禁用；中文文章仍可切换简繁显示。关联列表请求失败应提示失败，不能当作没有版本。
6. 切换失败或关联失效时，保留原正文、语言与链接，允许重试，不替换成其他概念。

修改查询词按 Enter 是新标题查询，使用当前显示的百科站点；新选区重新打开时回到书籍初始站点规则。切语言不改写原查询词，也不会自动再提交该查询词。

## 5. 内容、状态与生命周期

- 正文首版为 Wikipedia 真实纯文本导言，保留段落；完整文章通过原文箭头访问，不做全文章节阅读器或 AI 摘要。
- 保存本次查询词、当前站点、文章 pageid／实际标题／原文地址及官方语言关联；不需要候选实体、QID、持久化查询历史或目标语言偏好模型。
- 输入框获得焦点后仍能使用已复制的选词；DOM/Range 留在 reader 内。
- 新查询、切语言、关闭或切书后，旧响应不能覆盖新状态。关闭结束请求，保留书籍阅读位置，不产生注释或材料关系写入。
- 加载、未找到、请求失败分开处理；失败可重试，不缓存成未找到。未找到且无有效文章时 `↗` 不可执行；切语言失败时继续指向原文章。

## 6. 代码复用与最小接入

| 现有位置 | 用途 |
| --- | --- |
| `src/client/features/reader/readerRuntime.ts` | 使用 `ReaderSnapshot.selection` 纯数据 |
| `src/client/features/annotations/selectionController.ts` | 复用选区生命周期，不新增全局选区监听 |
| `src/client/features/workbench/ReadingWorkbench.tsx`、`workbenchStore.ts` | 接入入口和查询状态，不调用创建注释命令 |
| `src/client/infrastructure/epubParser.js` | 读取已有书籍 language 元数据 |
| `src/client/infrastructure/storageClient.ts` | 借用 HTTP／desktop bridge 分流模式，Wiki 不进入存储路由 |
| `src/desktop/preload.cjs`、`src/desktop/ipc.cjs`、`src/server/server.js` | 复用校验和本地服务架构，承接百科读取 |
| `src/desktop/assets.cjs`、`src/desktop/security.cjs` | 保留 CSP 和导航限制，原文经验证后用系统浏览器打开 |

采用 MediaWiki Action API 的标题／重定向解析、info、extracts、pageprops、langlinks。远端请求由本地 Node 服务／Electron 主进程执行；不加载扩展 content script，不嵌入 iframe，不新增 Wikidata provider。

开发时可参考 [WikiLens 可借鉴实现与适配表](resources.md#wikilens-可借鉴的实现)：请求与界面分离、旧请求取消及响应序号、正文优先、轻量成功缓存、Enter 提交和原文地址传递。该表包含固定版本源码链接、不可沿用的错误／语言处理及许可边界；不要求移植其扩展设施或 UI，也不增加本期功能。

请求链：原词查文章与导言 → 获取该文章语言关联 → 用户选择后取对应版本。处理 langlinks continuation，避免只显示首批语言；这是完整读取语言关联，不是候选搜索分页。

保留必要约束：限定 Wikipedia HTTPS 站点和外链、正确编码标题、识别 HTTP/API 错误、超时与取消、尊重限流、只发送主动查询文字、纯文本呈现、来源归属与许可。

缓存和请求去重可轻量实现，不作为用户功能。撤销旧文档的固定缓存数量、TTL、并发数量与 300 字限制，不建配置系统。无额外数据库迁移。

## 7. 多余功能审查结果

| 从当前实施要求中移除 | 原因 |
| --- | --- |
| 短语相关搜索、候选排序／分页、其他结果入口 | 用户要求按原词查询，未命中由用户改词 |
| 消歧义候选列表及多级候选流程 | MVP 使用提示和原站入口，不扩建搜索系统 |
| Wikidata 标签／别名／实体搜索、sitelinks 补救 | 切语言只使用已找到条目的官方关联 |
| 目标语言优先加载、自动英文回退、源目标双语言设置 | 先显示查到的条目，再由用户手动切换 |
| 语言偏好持久化及保存失败状态 | 不是当前 MVP 要求 |
| 自动语言识别、脚本提示、语言修正入口 | 不增加语言系统复杂度 |
| 无关联后专门进入目标站搜索 | 无对应版本就不提供该语言 |
| 独立 Search 按钮、额外标题行、选词回顾、常驻工具栏 | 使用用户指定的极简设计 |
| 图片、音频、事实卡片、全文目录、收藏、历史、AI 翻译／总结 | 不属于本期，第三方有这些能力也不是采用理由 |

加载失败、空导言、消歧义提示、请求取消、归属许可属于基本正确性处理，保留但不扩充常驻功能。WikiLens 仅为参考，未决定复制其代码；不再因它没有短语搜索而判断其不满足本期原词查询。

## 8. 验收

| 场景 | 预期 |
| --- | --- |
| 选中“蛋壳”点击入口／已有别名重定向 | 查原词或维基已有关联，显示真实导言，无注释副作用 |
| 不存在的完整短语 | 提示未找到，不剪词、不调用搜索候选或实体接口；支持改词 Enter |
| 消歧义／章节重定向／空导言 | 正确提示并保留适用原文入口，不伪造解释 |
| 中文文章打开语言选择 | 只列实际关联，选择前不自动加载英文正文 |
| 手动选择 English | 加载对应条目，正文、语言、原文地址一致更新 |
| 无其他版本／关联列表失败 | 分开处理，不伪造语言选项 |
| 版本切换失败 | 原正文、语言、链接一致保留，可重试 |
| 编辑查询词 Enter | 在当前站点按原样新文字查询，不翻译 |
| 长正文 | 独立滚动，顶部固定，首行缩进不用写入空格 |
| 关闭、换词、切书、迟到响应 | 旧响应不覆盖新状态，不改变阅读位置 |
| 断网、超时、429、API error | 失败不冒充未找到 |
| `↗` 与原入口 | 箭头打开当前版本原站；原入口退出；右上角没有关闭按钮 |

实现时运行项目基线 `npm run build`、相关行为检查和 `npm run test:reading-workflow`；修改 Electron IPC 时运行 `npm run test:desktop`。界面按项目要求验证鼠标／键盘、编辑、语言切换、滚动、退出及外链；安装包另行验证网络与原文打开。

规格整理时仅核对 Figma 元数据；后续开发已读取完整设计上下文及截图并接入源码。当前验收证据以[实现与验证记录](implementation.md)为准，不据此声明安装包已交付。
