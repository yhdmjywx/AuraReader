# AuraReader 官网展示

原截图展示位使用英文 Alice 第一章节选，默认单页、Literata。高亮、批注、选区及页边笔记直接复用当前应用的标注模块和样式；批注红线保留颜色 #ef4444、粗细 2px、偏移 3px，并同步 text-decoration-skip-ink: none。

## 直接打开

可以直接双击 dist/index.html。没有 iframe、ES module 请求、跨页面通信或字体等待关卡；普通脚本与内嵌字体在本地文件和 HTTP 下使用同一套产物。

## 演示与体验

- 首屏紧凑留白，补入第三段短文；保持 16px Literata 和完整行显示。
- 进入展示位后循环演示两处黄色高亮与两条页边批注；支持暂停、继续、重播。
- 演示统一以 1.3 倍速度播放，按正文顺序完成第一段高亮、第一段批注，再进入第二段靠前位置高亮和批注。导出预览按原导出器的段落顺序显示正文与对应笔记，紧凑排版，不自动向下滚动。
- 演示光标在高亮步骤之间和循环重播时连续移动；工具栏隐藏后保留最后有效位置。
- 点击“笔记”后隐藏演示光标，输入与保存期间持续隐藏；保存完成后在笔记外侧重新出现，再平滑移向下一步。
- 首轮完成标注后，通过原应用的“导出与备份 → 按章节导出 → 当前章节”切换到 Markdown 结果展示。后续自动循环跳过导出；手动“重新播放”会再次包含导出。
- 结果界面仅用文字标识 Markdown in Obsidian / VS Code，统一采用 Obsidian 风格；没有外观切换按钮或窗口装饰圆点。正文中的高亮保留为 `<mark>`，笔记按原导出器规则放在对应段落后，包含“原文引用”和笔记内容。
- 导出结果直接调用原应用的章节 Markdown 生成函数，展示层只渲染该输出的标题、段落、高亮和引用块；不引入通用 Markdown 解析器，不触发下载或系统文件对话框。用户接手后也可从相同菜单查看自己的标注结果。
- 底部蓝色 Try it yourself 停止当前演示，清空全部演示标注，再开放操作。输入中的批注也会清除。
- 接手前，播放和暂停状态均锁定阅读器与导出结果内部的鼠标、键盘编辑及剪贴板输入，只开放外部播放控制条；内部控件不进入 Tab 顺序。播放脚本的选区和控件操作单独放行，接手后恢复正常交互。
- 用户接手后不再自动播放；Start over 清空重来，观看演示返回循环。
- 固定单页，不加载分页、目录、书库、字体选择、全屏等功能。顶部这些按钮保留外观（包括阅读器内的全屏按钮），仅供界面展示；导出按钮开放上述预览交互，备份与恢复条目保留外观。
- 官网展示框外的“展开”仍可放大展示区域。
- 体验记录及恢复缓冲只存在本页内存，不上传、不写浏览器存储、不接触桌面书库。

## 开发

在仓库根目录已安装开发依赖的前提下，在 website 目录执行：

~~~powershell
npm run build
npm test
~~~

可选 HTTP 预览：npm start 后访问 http://127.0.0.1:4174 。

build-demo.cjs 打包标注模块、章节导出菜单与导出器，输出 showcase.bundle.js；原应用样式加作用域后输出 showcase-reader.css，避免影响官网。默认字体和少量图标以内嵌字体输出 showcase-fonts.css。showcase-build.json 记录复用源码哈希及构建信息，测试会核对与当前源码一致。

不加载完整阅读器启动器、图书解析、SQLite/HTTP 服务、桌面桥接或整套字体。桌面端源码和工作区已有修改保持原样。

## 部署

将整个 dist 目录部署到 Cloudflare 即可，不需要后端或云端数据库。当前不执行线上部署。
